# 人与 AI 科研协作工作流

**Human–AI Research Workflow · v4.4.0**

帮助人与AI把研究问题推进到可信结果、论证和投稿前材料。共同原则跨研究类型使用；公开数据、组学、湿实验、动物、临床、系统评价及方法研究按设计加载相应要求，其他领域可裁剪采用。不依赖单一疾病、平台、AI产品或固定目录。

核心是明确科学增量和不同答案的意义，先核致命条件，按证据解释结果，在重要取舍时给出推荐与理由，保留真实决定、版本和失败。单次答疑/局部修改用轻量流程，不因此创建完整研究管理结构。

## 使用入口

让助手读取[SKILL.md](SKILL.md)，再按当前任务选引用文件。持续项目可说：

> 初始化本项目并启用持续协作。

已有项目先恢复原入口、方案与有效授权，不重新立项；持久绑定与加载验证见[USAGE.md](USAGE.md)。辅助脚本可选，使用Python 3.9+标准库，先dry-run再初始化；不会自动迁移原目录或证明研究成立。

结构检查、AI情景评估与科学证据分开。维护方法见[情景评估](references/behavioral-evaluation.md)；脚本不是研究代码沙箱，同一状态由单写入者维护。具体方法、伦理、作者责任与投稿要求按研究实际确认。
