# 数据登记与可行性

- **作用**：登记实际数据版本、许可、单位、质量和处理路径。
- **不负责**：不替代文献索引、原始数据、运行日志或批准记录。
- **读者**：数据执行者、负责人和复核者。
- **更新触发**：首次使用数据、版本/变量/许可变化、可行性结论改变。
- **相邻文档**：数据用 `DATA-*`；相关论文/字典用 `REF-*` 并引用 `references/INDEX.md`；接触及决定分别见 EXPOSURE_LOG 与 F/D/CH 记录。
