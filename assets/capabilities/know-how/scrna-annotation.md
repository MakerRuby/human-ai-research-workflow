# 单细胞注释与组间比较

## 推荐流程

1. 质控：每个样本分别看 UMI 数、基因数和线粒体比例的分布，按分布设阈值，不套用固定值；对 snRNA-seq 要单独考虑核糖体和线粒体读段。
2. 环境 RNA 与双细胞：按需做环境 RNA 校正（如 SoupX、CellBender），并检测双细胞（如 scDblFinder、Scrublet）。
3. 归一化、高变基因、降维；有多个样本或批次时，做整合并评估效果（整合不能抹掉真实的生物学差异）。
4. 聚类与注释：用已知标志基因与参考图谱（如 CELLxGENE）互相印证；注释粒度与研究问题匹配；记录分辨率参数。
5. 组间比较：以供体或样本为独立单位，用 pseudobulk 做差异表达。细胞比例变化用考虑组成性质的方法（如 scCODA、propeller）。

## 该做与不该做

- 该做：以供体数报告样本量；保存每一步的参数与软件版本；保留未被注释的细胞群并说明。
- 不该做：把细胞当作独立样本做组间检验（伪重复）；为了得到“新细胞亚群”反复调分辨率；只凭单个标志基因定义细胞类型。

## 常见坑与对策

| 坑 | 症状 | 对策 |
|---|---|---|
| 伪重复 | 细胞层面的检验得到极小的 p 值 | 改用 pseudobulk，以供体为单位 |
| 双细胞被当成新亚群 | 一个群同时表达两种细胞类型的标志基因 | 做双细胞检测，并核对群的 UMI 分布 |
| 应激或解离效应 | 即刻早期基因（FOS、JUN）在部分群中升高 | 对照文献中的解离应激基因集，并在讨论中说明 |
| 过度整合 | 疾病特异的细胞群在整合后消失 | 比较整合前后的结果，用生物学阳性对照检验 |

## 工具选择

| 情况 | 推荐 | 理由 |
|---|---|---|
| Python 生态 | Scanpy + scvi-tools | 生态完整，便于和项目代码衔接 |
| R 生态 | Seurat + muscat（pseudobulk） | 与 Bioconductor 工具衔接 |
| 参考映射注释 | Azimuth / CellTypist 等，结果需人工复核 | 加快注释，但参考集偏倚会被继承 |

## 验证清单

- [ ] 每个样本的质控分布和过滤比例都已记录
- [ ] 主要细胞类型的标志基因热图与参考一致
- [ ] 组间结论以供体为单位，且换一种方法后仍然稳健
- [ ] 关键发现在独立数据集或其他方法（如 IHC、流式）中得到支持，或被标为待验证

## 排错

| 报错或异常 | 可能原因 | 处理 |
|---|---|---|
| 聚类主要按样本分开 | 批次效应 | 整合，并检查整合效果指标 |
| 某个群几乎全是线粒体基因 | 低质量或死亡细胞 | 回到质控步骤 |
