# bulk RNA-seq 差异表达

## 推荐流程

1. 核对样本表：分组、批次、配对或个体、测序批次、文库类型（链特异性）。确认分析单位是生物学重复。
2. 定量：FASTQ 用 nf-core/rnaseq 或 Salmon；记录参考基因组与注释版本（如 GENCODE 版本号）。需要时调用 `bulk-rnaseq` 技能。
3. 质控：文库大小、比对率、基因体覆盖、样本相关性与 PCA；找离群样本和样本错配（如用性别基因核对）。
4. 建模：输入计数，不能用 TPM 或 FPKM。Salmon、kallisto 等的转录本定量结果，要经 tximport（或 tximeta）导入并汇总到基因层面，同时保留长度偏移（DESeq2 用 `DESeqDataSetFromTximport`），而不是把四舍五入后的估计计数直接当作原始计数。设计公式包含已知的批次或配对项，例如 `~ batch + condition`。可调用 `pydeseq2`，或 R 的 DESeq2、edgeR、limma-voom。
5. 对比与校正：明确写出 contrast；用 FDR（BH）校正；需要排序或作图时，用与系数匹配的 LFC 收缩。
6. 报告：效应量与不确定性、阈值、背景基因集（供富集分析使用），以及软件和参考版本。

## 该做与不该做

- 该做：在看结果之前写好设计公式和对比；把全部检验结果连同背景基因一起保存。
- 不该做：多次调整阈值或剔除样本，直到结果“好看”；仅凭 p 值排序；把技术重复当作独立样本。

## 常见坑与对策

| 坑 | 症状 | 对策 |
|---|---|---|
| 批次与分组完全混杂 | 两组恰好来自不同批次 | 统计上无法分离；如实报告，设法补样本或用独立数据验证 |
| 样本错配或标签互换 | PCA 中个别样本落在另一组，性别基因与标签不符 | 回查原始样本表；改动登记 `CH-*` |
| 低计数基因 | 离散度估计不稳定，多重校正负担重 | 先做轻度预过滤（如 DESeq2 文档示例：至少达到最小组样本数的样本中计数 ≥10；edgeR 用 `filterByExpr`），阈值在看结果之前设定并记录；之后再依赖工具内置的独立过滤，不要为了结果反复调阈值 |
| 注释版本不一致 | ID 映射丢失大量基因 | 定量与注释使用同一版本，并记录 |

## 工具选择

| 情况 | 推荐 | 理由 |
|---|---|---|
| 常规两组或多因素 | DESeq2 / PyDESeq2 | 负二项模型，文档完善 |
| 复杂设计、需要随机效应（如重复测量、同一个体多样本） | variancePartition 包的 dream（基于 limma-voom 框架） | 支持线性混合模型 |
| 样本很少（每组 2 个） | edgeR 或 DESeq2，并如实报告检验效能有限 | 无法通过换方法弥补样本量不足 |

## 验证清单

- [ ] 样本数、分组和批次与样本表一致
- [ ] 已知阳性基因（如处理的直接靶标）方向符合预期
- [ ] p 值分布无异常（如不是呈 U 形）
- [ ] 结果在去掉单个离群样本后基本稳定（敏感性分析）

## 排错

| 报错或异常 | 可能原因 | 处理 |
|---|---|---|
| 模型矩阵不满秩 | 设计中某一水平组合缺失，或变量间共线 | 检查设计表，合并或去掉冗余项 |
| 大量基因 padj 为 NA | 独立过滤或检测到离群值 | 查看计数分布，按文档解读 |
