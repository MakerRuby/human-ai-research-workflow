# 公共数据选题：先核能否完成证据链

适用：以现有公共数据为主要资源，选择、收窄研究问题，或为探索线索寻找外部支持时。CP1–CP2 先做低成本筛查，CP4/G2 再实际核实，CP7 控制验证效应解锁。不增加新的关口编号；复用方案、数据登记和接触记录，已有答案只引用。

## 1. 将增量与资源同时筛查

先按 [问题塑形](question-shaping.md) 写清“已有认识 → 本研究可能改变的认识”，再列出支持这项改变不可缺少的证据。不能因为一个数据集容易分析就认定值得做，也不能把尚无着落的联合测量、临床队列或未来合作写成当前可执行主线。

在承诺主体分析前，用一张简表回答下列问题。标明已核实、上限或未知，附实际来源定位，不以数据库介绍或文章总人数代替。

| 对象 | 最小核查 |
|---|---|
| 要改变的认识 | 相对最接近原始研究的具体差别；什么相反或无结论结果仍有信息量 |
| 必要测量 | 暴露、结局、时间、关键协变量及其真实公开文件；RNA代理与功能、活性、临床检测分别表述 |
| 分析单位 | 独立个体/供体、重复时间、区室、细胞、技术重复、不同归一化列分别计数 |
| 配对依据 | 作者映射、样本表或原始记录如何把测量连接到同一个体；同号后缀和文件名相似只作线索 |
| 可用人数 | 针对每个目标分别列完整案例数及最乐观上限；主问题不强制采用所有次要测量的交集 |
| 来源与目标条件 | 患者重叠、招募中心/时间、干预前后、采样窗口、区室、平台；同疾病名不等于同条件 |
| 证据链后半段 | 该论断是否需要外部验证、独立重复或正交测量；若需要，具体资源、人数上限和关键缺口是什么 |

仅有发现数据、验证路径未知时，可以批准有边界的探索，但须明确输出是线索及其限制。独立验证并非所有描述研究的通用要求；是否不可缺少取决于目标论断与设计。不能在保留原承诺的同时，把缺失的验证默默改名为“稳健性”。

## 2. 用乐观上限尽早排除不可行路线

如果最乐观的独立人数、事件数或有效配对数已无法区分问题关心的几种答案，就先处理这一致命条件，不必为了填齐清单下载大对象或读取新效应。上限可行也不表示真实可用人数或设计已通过。

- 根据目标量选择区间宽度、可区分效应、功效或其他适合设计的诊断；交代依赖结构、调整参数、缺失和测量误差。无需统一设定最低人数或“80%即可发表”。
- 给出多种有科学意义的情景；发现集中较大的已见效应只能作为可能偏乐观的情景，不能当作独立真值。
- 写清近似方法的适用限制，尤其是极小样本、秩统计、过多协变量和退化重采样。实现护栏、近似不可用与数学上完全不可估计分别说明。
- 假设区间/功效标为规划值，不写成新队列结果。合理替代模型或收窄目标若改变科学问题，交负责人决定；不为放行而事后删协变量、合并区室或增加检验。

## 3. 提前核元数据，后解锁验证效应

CP7 的锁定要求针对验证分析及其结果解释，不能把它理解成“发现完成后才开始找验证资源”。独立来源、配对、人数上限、字段和许可应尽早核查。

每轮写明允许读取的层次：元数据/作者代码的静态身份赋值 → 测量结构或预定QC → 目标读出/效应。成员覆盖、表达指纹、嵌入和带目标信号的QC可能产生结果接触，不能自动归入无效应元数据。只读取实际需要的字段，作者代码不因用于查身份就直接执行。

来源谱系、个体身份、目标条件和精度可行后，再按获批版本冻结成员、映射、模型和报告规则，并解锁验证效应。不同时间/干预/平台下的证据可定位为推广或扩展，不能自动称同条件复现。内部重跑、独立数值实现和新患者的生物学确认分别记录。

## 4. 有边界地取证和停止

按致命条件排序，先取官方文件目录、样本表、表头、作者映射和必要方法定位，再决定是否取全矩阵。按资源设置合理的请求次数、时间/字节上限和替代路径；不强加固定次数。

访问失败、资源未定位、已取得但不能配对、已配对但精度不足是不同结论。保存状态码、与排错相关的响应摘要、部分文件及完整性校验；同一路径无新依据不反复整文件重传。官方新路径或可靠恢复方式可在原预算内尝试，成功记录不覆盖历史失败。

负责人已采用“条件不足则退出”等明确规则时，条件实际触发后按授权停止依赖工作并报告证据，不再索要同一确认。条件含糊、证据矛盾或需改问题时交负责人。停止当前路线不等于证伪生物现象，也不证明全部公共数据永久无解；保留原始观察、负结果及适用范围，避免用持续补分析代替新问题选择。
