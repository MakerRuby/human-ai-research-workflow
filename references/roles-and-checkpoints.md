# 角色、检查点与简报

本页维护人机分工、科学取舍和简报格式。关口证据见[研究关口](research.md)，领域差异见[研究类型](research-types.md)；项目日常执行见[工作流程](workflow.md)。

## 1. 分工与决定权

| AI角色 | 职责与产物 |
|---|---|
| 问题教练 | 澄清研究对象、比较、读出及不同答案的意义，形成问题卡 |
| 证据测绘员 | 核最接近工作、支持与反证，维护证据地图和检索起点 |
| 竞争解释组织者 | 提出判别性预测，按需要用简表或锦标赛确定优先核查对象 |
| 执行工程师 | 按实际能力执行与检查，交回输入/方法版本、产物和失败证据 |
| 红队与模拟审稿人 | 寻找实质缺陷及替代解释，把意见回到原文、设计或数据核实 |
| 书记官与叙事编辑 | 将有效决定、关键结果和局限写入论证及相关章节 |

角色不是必须创建的六个代理。用户及项目约定决定AI可自主判断的范围；科学/资源的重要取舍由约定责任人决定。伦理、作者身份和机构审批须有真实依据，委托AI审阅不产生真人签字。

## 2. CP0–CP9：按实际触发对齐

| 编号 | 时机与要决定的问题 | 所需材料/记录 |
|---|---|---|
| CP0 | 启动：目标、起点与约束是什么 | 已有信息与关键缺口；BRIEF |
| CP1 | 问题塑形：采用什么问题表述 | 问题卡、可比较表述及理由；Q/D |
| CP2 | 增量评估：继续、收窄、转向还是停止 | 证据地图、答案矩阵和投入边界；G1/D |
| CP3 | 选择解释或路线：优先检验什么 | 竞争解释表或锦标赛，判别性预测；H/D |
| CP4 | 可行性探针后：资源能否支持目标 | 实际数据/模型/实验条件、致命缺口；G2/D |
| CP5 | 正式执行前：采用什么设计与判定规则 | 方案、对照、信息量依据、预期结果；G3/D |
| CP6 | 关键读出后：说明什么、下一步投什么 | 解释简报；F及需要时D |
| CP7 | 需要验证/支持时：是否解锁或执行 | 已锁规则、来源/条件/精度、接触记录；D |
| CP8 | 叙事锁定：哪些论断成立、缺口怎么处理 | 骨架、结果链、实质审阅；NARRATIVE/D |
| CP9 | 投稿前：材料是否就绪、拟投何处 | 最新要求、对账、真实声明、固定包；D |

不是每次修改都重走检查点。可以合并已有充分依据的选择，在相关决定中说明不适用部分；不为凑齐编号另造审批。选定待检验解释时须有CP3依据，简表足够就说明无需锦标赛的理由。检查器只提醒部分登记缺口，不证明所有CP内容充分。

### 决策卡与连续执行

涉及新取舍时，用已有记录给出简短决策卡，详证放附件：

```text
要解决并决定的一件事：
推荐、理由和关键证据：
最强反对理由、其他可行选项：
主要代价、可逆性与不确定性：
需要的承诺；未决定时既有授权允许做到哪一步：
```

先通俗解释问题与理由，再列技术方案。一次选择对应一个明确承诺；“先评估是否值得”不批准后续执行。新答复只更新实际覆盖的依赖，已有决定仍适用时沿用；不以负责人否决次数评价协作，也不为制造分歧增加选择题。

已批准工作包连续完成并验收再汇报。读文件、修报错、出图、后台任务开始/结束不构成等候“继续”的理由；后台结束后主动验收。只有超出授权、出现新科学/资源取舍或确有阻塞时暂停依赖工作，并给出可审查选项。已采用的明确停止条件命中时按原决定执行并报告；条件含糊再澄清。

## 3. 意图与解释简报

**意图简报**用于非平凡研究任务开工前，可并入已有任务材料，覆盖：

```text
任务及服务的Q/H/预期CLAIM：
为什么现在做；拟填哪个证据缺口：
不同结果及无结论分别意味着什么：
投入边界、前置条件与停止规则：
产出位置与检查方法：
```

不要为每个备选项另建完整意图文件。采用后需登记的简报用`research_tree.py task intent`记录；更新预期用新路径保留旧版。新运行的绑定、快照及旧记录核查以[复现协议](reproducibility.md)为准；登记失败不继续依赖运行。

**解释简报**用于关键或意外读出：

```text
质量/对照是否支持解释；哪些环节尚不成立：
事实观察及RUN/EXP/数据编号：
对应哪种预期、有哪些合理竞争解释：
回答了什么问题，仍不能区分什么：
影响哪些问题/假设/论断；推荐下一步及理由：
```

质量不足时先定位影响，暂停依赖解释，不把无效测量读成生物结论。信息量弱、主张收窄或支持失效时，按[投入审阅](research-value-review.md)在原卡片中分别判断可信度、科学答案和下一块投入价值。

## 4. 审阅的执行方式

对偏差敏感且宿主/授权允许时，用未见生成过程或已有评语的上下文审阅；无法隔离就注明限制。多AI一致仍是意见，独立实证依靠原始来源、已知答案、不同实现或适当的独立研究设计。需要专业判断时如实记录实际评审者及其角色，不以脚本替代。
