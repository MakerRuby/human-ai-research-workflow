# 问题塑形、现状与科学增量

用于CP0–CP2的问题澄清和立项依据。竞争解释见[CP3](hypothesis-tournament.md)，设计与资源见[研究关口](research.md)，决定与简报格式见[角色与检查点](roles-and-checkpoints.md)。

## 1. 先读已有材料，再问缺口

只询问会改变下一步判断的信息，可合并、跳过已有答案，不固定题数：问题从何而来；已读/已做与失败经验；希望改变的认识或用途；现有资源、约束和伦理条件；不同结果及退出条件；负责人已有解释。已有假设注明真实来源，不因来自负责人而优先判真。

## 2. 澄清度用于定位缺口

| 级别 | 当前能说明什么 | 主要缺口 |
|---|---|---|
| L0 主题 | 一个领域或兴趣 | 具体问题 |
| L1 现象/空白 | 要解释或补充什么 | 对象、范围、参照与读出 |
| L2 可回答问题 | 单位、比较/参照、目标量及适用时间明确 | 可区分的答案与证据 |
| L3 可检验目标 | 假设和预测，或明确的描述/估计/基准目标 | 操作定义与可行设计 |
| L4 可操作 | 测量/证据、设计、资源和信息量有依据 | 最终取舍与解释规则 |
| L5 决定就绪 | 答案矩阵、关键反证、投入及退出条件明确 | 执行与更新 |

CP1的问题应至少可回答，CP5须具备可操作设计；级别是诊断标签，不是新增审批。描述、估计、资源或方法研究不必构造生物机制，也不要求所有问题沿因果证据层级升级。

按实际缺口补全：独立单位与重复；比较能排除什么；操作定义与测量误差；设计能支持描述、关联、预测、因果还是机制；最普通的混杂/伪影解释；什么反证会改变问题；不同答案改变哪些理解或行动。知识约束本身可有价值，不要求立即转化。

临床问题可用PICO/PECO补时间关系；实验问题用系统、扰动、读出和对照；系统评价明确问题、纳排与证据综合对象；方法研究明确任务、参照、基准和泛化目标。具体表型判据由本领域方法/共识核实，不把单一指标或一种模型的例子变成通用定义。

## 3. 证据地图

检索前查`references/SEARCH_LOG.md`，按[来源协议](evidence-and-materials.md)保留有用材料。在`references/EVIDENCE_MAP.md`按根问题记录已确立认识、争议、空白、最接近工作及必要的竞争动态，附实际检索范围和日期；不固定论文数量或回溯年限。

明确最近工作做了什么、没回答什么、局限在哪里。检索不足不写“首次”；未见报道只能对应真实检索范围。方案引用证据地图，不复制整套材料。

## 4. 科学增量与答案矩阵（CP2）

推荐前用具体对象说明：**已有研究知道什么；本研究仍能区分或约束什么；不同答案增加什么认识。** 附原始依据与可取得的证据。增量可以来自现象、解释、解决矛盾、方法/资源、推广、重复验证或有信息的负结果；换名称、算法或图件本身不自动构成贡献。

首次推荐就呈现背景直接程度、实质差别和最强反对理由，区分：

- **线索**：关键依据尚缺。
- **有限核查**：清楚要裁决的未知、成本和停止规则。
- **建议立项**：问题价值和最小证据链已有足够依据。

评估意义、差别、证据可及性、可区分程度、风险与代价；理由和来源比总分重要。仅在有助比较时评分，不让高总分补偿不存在的关键测量。公共数据另核[人数/配对/支持路径](public-data-feasibility.md)，其他设计核相应证据单位。

| 可能答案 | 现在能说明什么 | 可支持的论断 | 下一步及价值 |
|---|---|---|---|
| 支持预期 | | | |
| 约束或反对预期，信息量足够 | | | |
| 条件性/异质性 | | | |
| 无结论或技术失败 | | | |

据此建议继续、收窄、转向或停止，形成G1及真实决定。转向时说清保留/放弃的目标、论文类型或对象变化及新增代价；允许当前没有合格主线，不用剩余可运行数据代替科学理由。累计筛查收敛见[工作流程](workflow.md)。

## 5. 问题树与下一步

持续研究用Q问题、H假设、F发现和CLAIM论断连接任务。当前表述、状态与链接在state；`HYPOTHESES.md`保存论证，用ID引用而不重抄状态。写入命令见[工具说明](tooling.md)，字段见[状态结构](state-schema-v2.md)。

下一步优先消除最可能改变判断、代价合理且能填关键证据缺口的不确定性；比较依赖、失败损失和资源约束，不机械计算无依据的“价值/成本”分数。提出必要备选和推荐即可，采用后再为非平凡任务登记意图，不为每个候选另建文件。
