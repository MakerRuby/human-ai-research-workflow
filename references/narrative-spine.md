# 论证骨架与边做边写

本页维护从证据到论文的连接。来源细则见[证据协议](evidence-and-materials.md)，科学价值与实质审阅见[投入审阅](research-value-review.md)，投稿文件规范与打包见[固定交付](release.md)。

## 1. 骨架服务于证据

论文说明发现了什么、为何可信、增加什么认识。结果改变就改论证，不挑选结果维持故事；事后形成的假设和偏离如实披露。关键方法、结果和解释形成时写入相关章节素材，不把每个治理产物或技术诊断都写进正文。

研究项目的`manuscript/NARRATIVE.md`保存：当前问题/工作标题与证据表述；读者和意义；背景—空白—问题—方法—发现—局限的联系；图表/正文的论证分工；缺口；预期质疑与回应；目标期刊定位/要求核查日期；重要修订原因。细节引用Q/H/CLAIM、F/D及实际结果版本。

## 2. 按事件积累，避免预设故事

| 事件 | 更新内容 |
|---|---|
| CP2增量评估 | 最近工作、未解问题与关键反对理由；未知时写问题和可能答案，不预置结论 |
| 方法/设计定稿 | Methods素材和方案版本 |
| 来源/数据登记 | 真实定义、纳排、单位、许可及方法/可用性声明素材 |
| 关键结果验收 | Results与图表草稿、准确数字来源；失败/负结果同样保留 |
| CP6解释 | 解释、竞争解释与局限，实际改变的论断 |
| 审阅/关键变化 | 有证据的回应、未解决缺口和受影响章节 |

章节按需建立。每项正式研究工作先在意图中标明目标量、可能答案及报告用途（图、表、正文或审计），不强制都进入主图。预期CLAIM在方案/骨架预留，实际结果产生后再登记state的claims；不拿输入、方案或占位结果消除检查错误。

G1后证据地图/骨架仍空模板会被提醒；检查器不会逐项确认故事板覆盖或科学充分性。尚无结果、主线暂停/停止时可留空结果部分，说明真实原因并保留当时有效的论断和未解决问题，不清空历史。

## 3. 主线锁定（CP8）

主要结果到位后，复用[三项判断与实质审阅](research-value-review.md)，再整理：骨架变化；每条主要论断的证据链；图表各自问题与衔接；缺口、补做代价和不补的后果。图表核单位、比较、误差、选择与解释，也看实际导出可读性；规范核实后适配目标期刊，换样式不无故重算科学结果。

负责人据实际证据决定锁定、补做、收窄或转向，记录真实决定。锁定后主要结论变化按CH追踪标题、摘要、正文、图表和补充材料；工作稿编辑与固定版本保留见[目录规则](project-layout.md)。

## 4. 投稿前（CP9）

按已有检索范围做有针对性的更新及必要补检，核新近工作/反证。对账关键数字、CLAIM、图表与引用的实际来源和当前版本；仅对CP8后实质变化/未解决意见重审，不机械重做全部评审。

回应区分新增证据、表达澄清和仍未解决；补分析/实验须有实际范围授权。按[固定交付](release.md)核现行要求及必要真实声明，区分draft、ready与实际提交。作者同意、伦理、利益冲突等未确认时保留待办，不由AI补造。
